# gRPC Learning

This repository is a personal learning space for understanding **gRPC (Google Remote Procedure Call)** concepts and workflows.

## About gRPC

gRPC is a high-performance RPC framework that allows services to communicate across networks using strongly typed contracts (Protocol Buffers).

## Purpose of This Repository

- Learn core gRPC concepts
- Practice defining RPC services
- Explore client-server communication patterns
